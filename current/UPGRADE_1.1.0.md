# KARMA 1.1.0 — UX / Chat / Notes Upgrade

این نسخه برای ارتقای نصب موجود کارما طراحی شده است و دیتابیس یا فایل‌های Media را حذف نمی‌کند.

## مهم‌ترین تغییرات
- Quick Create برای پروژه و وظیفه
- نمایش و ورود گسترده تاریخ شمسی
- فارسی‌سازی بیشتر فرم‌ها و نماها
- چت پروژه با ظاهر Telegram-like
- پیش‌نمایش عکس/ویدئو/فایل قبل از ارسال
- نمایش درصد آپلود دایره‌ای با XHR Upload Progress
- بهبود ضبط و آپلود Voice
- دفترچه‌های شخصی Notebook / Section / Page مشابه OneNote
- پیوست تصویر، ویدئو، صوت و فایل در هر صفحه یادداشت
- چک‌لیست داخل همان صفحه یادداشت

## ارتقای نصب موجود
از داخل پوشه استخراج‌شده:

```bash
chmod +x upgrade-production.sh
sudo ./upgrade-production.sh
```

اسکریپت از کد فعلی بکاپ می‌گیرد، `.env`، محیط مجازی، Media و داده‌ها را نگه می‌دارد، migration و collectstatic اجرا می‌کند و فقط سرویس karma را restart می‌کند.
