# KARMA 1.2.0 — CRUD, Import/Export & Color UI

این نسخه برای **ارتقای نصب موجود** طراحی شده و داده‌های PostgreSQL را پاک یا Reset نمی‌کند.

## تغییرات اصلی

- دکمه‌های ویرایش/حذف برای میزکار، پروژه، همکار، وظیفه، فهرست، چک‌لیست، نقطه عطف، پیام شخصی خود کاربر، مستند، نامه، دفترچه، بخش، صفحه یادداشت و پیوست یادداشت.
- حذف میزکار و پروژه به‌صورت امن/بایگانی انجام می‌شود تا داده‌های فعلی در دیتابیس باقی بمانند.
- Export میزکار به JSON شامل اعضا، پروژه‌ها، فهرست‌ها، وظایف، چک‌لیست‌ها و نقاط عطف.
- Export پروژه به JSON شامل ساختار مدیریتی پروژه.
- Import میزکار و پروژه از JSON خروجی کارما.
- فایل‌های رسانه‌ای داخل JSON جاسازی نمی‌شوند و باید جداگانه نگهداری شوند.
- رابط کاربری خواناتر، رنگی‌تر، Action Menu، Hero، Status Pills و Action Buttons.
- فارسی‌سازی بیشتر برچسب‌ها و حفظ تاریخ شمسی نسخه 1.1.

## Migration دیتابیس

Migration جدید:

`projects/migrations/0002_project_is_archived.py`

فیلد `Project.is_archived` با مقدار پیش‌فرض `False` اضافه می‌شود. تمام پروژه‌های موجود بدون تغییر فعال می‌مانند.

## ایمنی داده

اسکریپت `upgrade-production.sh` قبل از Migration:

1. از کد فعلی Backup می‌گیرد.
2. از PostgreSQL یک `pg_dump` با فرمت custom می‌گیرد.
3. فایل `.env`، پوشه `media` و virtualenv فعلی را دست نمی‌زند.
4. Migration را روی همان دیتابیس موجود اجرا می‌کند.
