# KARMA 1.3.0 — User Identity & Admin Management

این نسخه برای ارتقای مستقیم نصب موجود طراحی شده و دیتابیس PostgreSQL فعلی را حفظ می‌کند.

## تغییرات اصلی

- صفحه مدیریت کاربران داخل خود کارما برای مدیران (`/management/users/`).
- افزودن کاربر با نام و موبایل؛ رمز اولیه پیش‌فرض `123456`.
- ویرایش نام، موبایل، فعال/غیرفعال، سطح Staff و رمز توسط مدیر.
- بازنشانی رمز یک کاربر یا همه کاربران به `123456`.
- نرمال‌سازی موبایل‌های فارسی/عربی، `+98`، `0098` و `98` به فرم واحد `09xxxxxxxxx`.
- تشخیص و ادغام حساب‌های تکراری بر اساس موبایل واحد.
- انتقال داده‌های کاربر تکراری به حساب اصلی: میزها، عضویت‌ها، دسترسی پروژه‌ها، وظایف، چت‌ها، اسناد، نامه‌ها، دفترچه‌ها، یادداشت‌ها و اعلان‌ها.
- ادغام WorkspaceMemberهای تکراری هر میز و حفظ قوی‌ترین Role.
- اضافه شدن `phone_normalized` به Profile با Unique Constraint دیتابیس.
- ارتقای Django Admin و اکشن‌های Reset Password / Merge Duplicates.

## ارتقای دیتابیس

اسکریپت `upgrade-production.sh`:

1. از کد فعلی Backup می‌گیرد.
2. از PostgreSQL با `pg_dump` Backup کامل می‌گیرد.
3. Migration میانی `accounts.0002` را اجرا می‌کند.
4. کاربران تکراری را بر اساس موبایل ادغام می‌کند و رمز همه کاربران را روی `123456` قرار می‌دهد.
5. Migration نهایی Unique Mobile را اجرا می‌کند.
6. Static را Collect و فقط سرویس `karma` را Restart می‌کند.

> هشدار امنیتی: `123456` یک رمز ضعیف است. این مقدار طبق نیاز پروژه به‌عنوان رمز اولیه اعمال می‌شود. پس از اولین ورود، به‌خصوص رمز مدیر اصلی را تغییر دهید.
